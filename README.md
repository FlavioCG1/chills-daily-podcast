# Chills Daily Podcast

RSS feed and audio hosting for the Chills Daily horror podcast.

- **RSS feed:** https://FlavioCG1.github.io/chills-daily-podcast/feed.xml
- **Submit to:** Apple Podcasts Connect, Spotify for Creators

## Adding a new episode
1. Extract MP3 from the video (128kbps, 44.1kHz) into `audio/`
2. Append the episode to `feed.xml`
3. Push — Apple/Spotify pull updates automatically
